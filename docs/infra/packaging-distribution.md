## Code Signing

### macOS
```bash
# Sign with Developer ID certificate
codesign --sign "Developer ID Application: ProCode Inc" \
  --options runtime \
  --entitlements build/entitlements.mac.plist \
  ProCode.app

# Notarize with Apple
xcrun notarytool submit ProCode.dmg \
  --apple-id "$APPLE_ID" \
  --password "$APPLE_APP_SPECIFIC_PASSWORD" \
  --team-id "$TEAM_ID" \
  --wait

# Staple notarization ticket
xcrun stapler staple ProCode.dmg
```

### Windows
```javascript
// build/windows-sign.js
exports.default = async function(configuration) {
  const { exec } = require('child_process');
  exec(`signtool sign /fd sha256 /tr http://timestamp.digicert.com /td sha256 "${configuration.path}"`);
};
```

## Auto-Update

### Configuration
```typescript
// apps/desktop/src/main/services/UpdateManager.ts
import { autoUpdater } from 'electron-updater';

class UpdateManager {
  constructor() {
    autoUpdater.autoDownload = false;
    autoUpdater.autoInstallOnAppQuit = true;

    autoUpdater.on('update-available', (info) => {
      this.notifyUser(info.version);
    });

    autoUpdater.on('update-downloaded', () => {
      autoUpdater.quitAndInstall();
    });
  }

  checkForUpdates() {
    autoUpdater.checkForUpdates();
  }

  downloadUpdate() {
    autoUpdater.downloadUpdate();
  }
}
```

## Bundle Size Optimization

### Current Targets
| Platform | Target | Notes |
|----------|--------|-------|
| macOS DMG | < 200MB | Universal binary |
| Windows NSIS | < 180MB | Compressed installer |
| Linux AppImage | < 170MB | Self-contained |

### Optimization Strategies
- Exclude dev dependencies from bundle
- Compress native modules
- Use Electron's asar archive
- Tree-shake unused code
- Compress with Brotli where possible
