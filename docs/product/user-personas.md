# User Personas

## 1. Alex — Senior Full-Stack Developer

**Demographics:** 28-35, 5-10 years experience, works at a mid-size tech company  
**Tech Stack:** TypeScript, React, Node.js, Python, PostgreSQL  
**Pain Points:**
- Context switching between IDE, terminal, browser, documentation
- AI tools that don't understand the full codebase context
- Spending hours on code review and documentation
- Onboarding new team members takes weeks

**Goals:**
- Stay in flow state — minimize context switching
- AI that understands project architecture, not just single files
- Automated code review and documentation generation
- Fast onboarding for new team members via knowledge graph

**How ProCode Helps:**
- All-in-one IDE with terminal, Git, AI chat, agents
- Knowledge graph provides full codebase context to AI
- ReviewerAgent and DocAgent automate repetitive tasks
- Knowledge Graph Explorer helps new devs navigate codebase
