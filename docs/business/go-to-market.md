# Go-to-Market Strategy

## Target Audience

### Primary: Individual Developers
- **Who:** Senior developers, tech leads, open-source maintainers
- **Why:** Frustrated with AI IDEs that send code to the cloud, want local-first privacy
- **Acquisition:** Developer communities (GitHub, Reddit, Hacker News, Twitter/X)
- **Activation:** Free download, no account required, works immediately

### Secondary: Engineering Teams
- **Who:** Small to mid-size engineering teams (5-50 developers)
- **Why:** Need consistent AI tooling across team, want knowledge sharing via graph
- **Acquisition:** Team referrals, conference talks, technical blog posts
- **Activation:** Free for teams up to 5, paid plans for larger teams

### Tertiary: Enterprise
- **Who:** Large organizations with strict data policies
- **Why:** Cannot use cloud AI tools, need on-premise AI assistance
- **Acquisition:** Security compliance certifications, enterprise sales
- **Activation:** Custom deployment, dedicated support

## Launch Strategy

### Phase 1: Developer Preview (Month 3)
- Core IDE features (Phase 1 deliverables)
- Free download, no account required
- GitHub repository open-source
- Collect feedback via GitHub Issues, Discord

### Phase 2: AI Beta (Month 6)
- Knowledge Graph + RAG features
- Local AI via Ollama
- Invite-only beta for AI features
- Blog posts showcasing capabilities

### Phase 3: Public Launch (Month 9)
- Multi-agent system
- Full feature set through Phase 3
- Public launch on Product Hunt, Hacker News
- Conference talks (React Conf, RustConf, etc.)

### Phase 4: Maturity (Month 12)
- Extension system, marketplace
- Performance optimization pass
- Enterprise features (SSO, audit logs)
- Paid plans for teams/enterprise
